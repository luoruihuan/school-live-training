# 校园直播实训平台操作手册

适用对象：教师、学生、学校管理员。截图为项目实际页面，示例课堂、商品名称及彩条画面仅用于演示，不代表正式教学内容。

## 1. 先看这里：入口与使用顺序

| 身份 | 访问入口 | 主要任务 |
| --- | --- | --- |
| 学生 | https://live.gaiademo.online/ | 观看直播、聊天、领券、积分兑换、查看订单与回放 |
| 教师 | https://live.gaiademo.online/admin | 准备课堂和商品、获取推流信息、使用 OBS 开播、处理订单 |
| 学校管理员 | 管理端同上 | 在教师能力基础上，管理账号和积分；权限以实际分配为准 |

> 两个入口使用同一域名下的登录会话。电脑上同时测试教师和学生时，请用不同浏览器或无痕窗口；不要在同一浏览器里反复切换不同身份。

**教师开课顺序**：登录 → 建店铺 → 建课堂 → 建商品并绑定本场 → 配优惠券（可选）→ 获取 OBS 设置 → OBS 开播 → 学生观看 → OBS 停播 → 查看回放。

**学生使用顺序**：领取账号 → 首次改密 → 登录学生端 → 进入课堂 → 领券/选商品 → 确认积分兑换 → 按订单自提或等待送货 → 课后观看回放。

## 2. 登录与首次修改密码（所有人员）

1. 从学校管理员处获取账号和初始密码，平台不开放自行注册。
2. 教师进入管理端；学生进入学生端。账号可以是学号、工号等，不必是邮箱。
3. 输入账号、密码，点击「进入工作台」或「进入课堂」。
4. 首次登录或管理员重置密码后，必须先修改密码：输入当前密码、新密码、再次确认新密码。
5. **新密码至少 12 位，不能与原密码相同**。保存后，使用新密码重新登录。

> 新建账号表单的默认初始密码是 `123456`，但请以管理员实际通知为准。初始密码不能长期使用，也不要把自己的密码发到聊天区。

![管理端登录页](screenshots/01-管理端登录.png)

![学生端登录页](screenshots/11-学生端登录.png)

忘记密码：联系管理员重置。提示「此入口仅供……使用」：先退出当前账号，再进入对应身份的入口。

## 3. 教师：课前准备

### 3.1 查看教学概览

登录管理端后，可查看待开播、直播中、待交付订单和有回放的课堂。侧栏是各业务模块入口；不同角色看到的菜单可能不同。

![教学概览](screenshots/02-教学概览.png)

### 3.2 创建店铺和直播间

1. 进入「店铺管理」，点击「新建店铺」，填写店铺名称，简介可选，保存。
2. 进入「直播间管理」，点击「新建直播间」。
3. 选择所属店铺、填写课堂标题，保存。
4. 在列表点击「配置本场」→「编辑课堂」，将准备好的课堂设为「待开播」。

| 状态 | 含义与处理 |
| --- | --- |
| 准备中 | 草稿，学生不可见；用于备课 |
| 待开播 | 课堂已开放，尚未收到 OBS 推流 |
| 直播中 | OBS 成功推流后自动更新，不需要手动设置 |
| 已结束 | 停止推流后自动更新；有录制时可查看回放 |

> 修改页面状态不会启动或停止直播。真正开播、停播必须在 OBS 中操作。

![直播间管理与配置本场入口](screenshots/03-直播间管理.png)

### 3.3 创建商品并绑定到本场

1. 进入「商品管理」→「新建商品」。
2. 选择店铺，填写商品名称、兑换所需积分和自提点，按需填写简介、上传图片。
3. 图片支持 JPG、PNG、WebP，最大 3 MB。保存后确认商品为上架状态。
4. 返回「直播间管理」→ 对应课堂的「配置本场」→「配置商品」。
5. 下拉选择**同店铺商品**，填写展示顺序（数字越小越靠前）。
6. 点击「选好商品后点这里绑定到本场」。确认弹窗下方列表已出现商品，再点「完成」。
7. 重新打开本场配置，核对「本场商品」显示已绑定数量。

> **只在下拉框选中商品，然后点「完成」，不等于绑定成功。** 必须先点击绑定按钮。商品管理是商品资料库，绑定后学生才能在对应课堂的小黄车里看到。

![商品管理](screenshots/05-商品管理.png)

### 3.4 配置优惠券（可选）

- 全局入口：「优惠券」页，查看各直播间的券，创建或停用。
- 本场入口：「直播间管理」→「配置本场」→「设置优惠券」，查看本场券列表；需要时点「新建本场优惠券」。

新建时填写名称、所属店铺、适用直播间、抵扣积分、到期日期，保存后核对适用课堂与有效期。

**规则**：每人每券限领一次、限用一次；只抵扣适用直播间的商品积分，抵扣不超过适用商品的小计；过期或被停用的券不可使用。券不是全校通用券，无需再次把它“添加”到已指定的课堂。

![优惠券管理](screenshots/06-优惠券.png)

## 4. 教师：OBS 安装、配置和开播（分步说明）

本节不包含 OBS 软件截图，按界面名称逐项操作。不同系统或语言版本中，「直播」「推流」「串流」可能是相近功能的不同译名，请以当前界面为准。

### 4.1 安装并获取本场推流信息

1. 从 OBS 官网 https://obsproject.com/ 下载适合电脑系统的安装包并安装。
2. 首次启动若出现「自动配置向导」、服务默认为 Twitch，可点击「取消」，使用下面的手动配置。
3. 在平台管理端进入「直播间管理」→「配置本场」→「获取 OBS 设置」。
4. 保留弹窗，分别复制其中的「OBS 服务器」和「OBS 串流密钥」。

**服务器格式示例**：

```text
rtmp://live.gaiademo.online:1935/live
```

**串流密钥格式示例（不是可用密钥）**：

```text
本场流名?token=系统生成的签名&expire=系统生成的时间戳
```

> 串流密钥必须完整复制，包括流名、`?token=` 和 `&expire=`。不要只复制 token，也不要把整条 RTMP 地址填进密钥框。有效期以平台弹窗显示为准；不要把密钥发给学生或放进公开文档。

### 4.2 设置推流服务器

OBS →「设置」→「直播/推流」：

| 字段 | 填写内容 |
| --- | --- |
| 服务 | 自定义 |
| 服务器 | 平台弹窗中的「OBS 服务器」 |
| 串流密钥/推流码 | 平台弹窗中的完整「OBS 串流密钥」 |

不需要连接 Twitch 账户，也不需要使用 Enhanced Broadcasting。

### 4.3 设置分辨率、帧率和编码

OBS →「设置」→「视频」：

| 配置项 | 建议起始值 |
| --- | --- |
| 基础（画布）分辨率 | 1920 × 1080，或保持显示器实际比例 |
| 输出（缩放）分辨率 | 1280 × 720 |
| FPS/帧率 | 25 或 30 |

OBS →「设置」→「输出」→ 将输出模式切为「高级/高阶」→「直播」页签：

| 配置项 | 建议起始值 |
| --- | --- |
| 视频编码器 | **H.264**；可选 Apple VideoToolbox H.264、NVENC H.264 等硬编，没有则 x264 |
| 速率控制 | CBR |
| 视频比特率 | 2000～2500 Kbps；人数增加时可降至 1200～1500 Kbps |
| 关键帧间隔 | 2 秒 |
| x264 预设 | veryfast（仅使用 x264 时） |
| 音频编码 | AAC |
| 音频码率 | 96 或 128 Kbps |

> 为方便手机观看，请使用 **H.264 + AAC**，不要为本场改选 AV1 或 HEVC/H.265。以上是起始配置，不是并发人数保证；实际体验还受观众数量、网络和其他流量影响。

### 4.4 添加画面和声音来源

1. OBS 主界面「来源」面板点「＋」。
2. 讲 PPT 或演示桌面：选择「显示器采集」「屏幕采集」或「macOS 屏幕采集」等对应来源，选择要共享的屏幕或窗口。
3. 若需教师出镜，再添加「视频采集设备」，选择摄像头，拖动缩放到画面角落。
4. macOS 首次采集若提示权限，到「系统设置 → 隐私与安全性」允许 OBS 录屏、麦克风、摄像头；按提示重新打开 OBS。
5. 在预览画面中右击来源 →「变换」→「适配屏幕」（如当前版本有此选项），避免只显示局部画面。
6. 对着麦克风说话，确认「混音器」对应音量条有波动，并且没有静音。

> 直播前关闭私人聊天、通知和敏感窗口。不要把正在播放直播的网页也采集进去，以免形成无限套屏；学生端试听时戴耳机，避免回声。

### 4.5 开播与停播

**开播检查**：预览有画面 → 麦克风有波动 → 本场服务器/密钥已填好 → 点击「开始直播/开始推流」。

1. OBS 出现推流时长和输出码率后，返回平台查看课堂是否变为「直播中」。必要时刷新页面获取最新状态。
2. 用另一浏览器或手机，以学生账号进入同一课堂，实际确认有画面、能听到声音。
3. 学生手机端首次起播可能需要等待切片和缓冲；没有声音先点击播放器取消静音。
4. 下课后，在 OBS 点击「停止直播/停止推流」。课堂随后变为「已结束」。
5. 等待录制完成、上传后，在平台「查看回放」检查；长场次上传需要更久，不保证停播瞬间就出现。

## 5. 学生：观看直播、聊天和领券

### 5.1 进入课堂

1. 打开学生端，使用学校分配的账号登录；首次使用按第 2 节改密。
2. 在「直播课堂」中找到教师通知的课堂，点击「进入课堂」。可按课堂名称或店铺搜索。
3. 教师也可分享课堂链接；链接不能代替登录权限。

![学生端课堂列表](screenshots/12-学生端-直播课堂列表.png)

### 5.2 播放、声音与互动

- 等待播放器出现画面，点击播放按钮；默认静音时，点击播放器音量按钮开启声音。
- 手机可使用浏览器全屏或横屏观看；微信内无法正常播放时，可尝试「在浏览器打开」。
- 在「课堂互动」输入文字后发送。请勿频繁连续发送，不要发送密码、地址等私人信息。
- 手机观看与电脑画面可能有时间差，不代表教师操作失败。

下面截图中的彩条是制作手册时的测试画面，正式课堂显示教师通过 OBS 发送的内容。

![学生观看与课堂互动](screenshots/13-学生端-直播间观看.png)

### 5.3 领取优惠券与选商品

1. 找到「本场优惠券」或点击「领券」，在需要的券旁点击「领取」。
2. 在「本场商品」中核对名称、积分价格，点击「加入」。
3. 手机端可点击「本场商品」「已选商品」或购物车入口展开小黄车。
4. 已领取不等于已使用，兑换时还需要在结算页选择该券。

## 6. 学生：积分兑换、提货与订单

1. 进入「购物车」或本场「已选商品」，确认商品和数量，移除不需要的商品。
2. 点击「去兑换」，核对积分余额、商品所需积分。
3. 在「使用已领取的优惠券」中选择适用券，核对优惠抵扣及实际扣除积分。
4. 选择交付方式：

| 交付方式 | 操作要求 |
| --- | --- |
| 自提（默认） | 查看各商品的自提点，按学校约定时间到现场领取；地点由管理员预先配置 |
| 送货 | 填写准确送货地点，例如楼栋、房间或约定地点；未填写不能提交 |

5. 核对无误后点「确认积分兑换」。余额不足时联系管理员充值，不需要在线支付。
6. 成功后进入「我的订单」，核对订单编号、商品、扣除积分与交付方式。
7. 自提时向工作人员出示订单；选择送货的，按学校约定方式等待线下交付。平台不提供快递轨迹。

![积分兑换结算示例](screenshots/14-学生端-积分兑换结算.png)

> 截图为结算演示：余额为 0，因此尚未成功兑换。正式操作请确保余额足够，并滚动到结算抽屉底部查看提交按钮。

![我的订单入口（无订单时的示例）](screenshots/15-学生端-我的订单.png)

提交时遇到网络错误：先去「我的订单」确认是否已经生成订单，避免盲目反复提交。商品价格变化、下架、券过期等情况，请重新核对后再兑换。

## 7. 学生与教师：课后回放

**学生**：打开「课程回放」→ 选择课堂 → 点击相应录制的「播放回放」。

**教师**：管理端「直播间管理」→「配置本场」→「查看回放」。

- 一间课堂可能有多条回放，暂停/断开并重新推流可能形成新的录制，请按日期时间选择。
- 支持暂停、拖动和调节音量；手机端受浏览器策略影响时，点击播放。
- 回放默认最多保留 180 天；磁盘紧张时，可能从最旧回放开始提前清理，水位清理不会提前删除未满 90 天的回放。重要课程请提前联系管理员安排留存，不要把平台当作永久档案库。

![课程回放入口](screenshots/16-学生端-课程回放.png)

## 8. 管理员：账号、积分与线下交付

### 8.1 建号和密码重置

1. 登录管理端，进入「账号管理」→「新建账号」。
2. 填写登录账号，选择教师或学生角色；姓名可不填，不填时使用账号作为显示名。
3. 默认初始密码为 `123456`，可按学校要求修改。保存后，单独通知本人账号、初始密码和正确入口。
4. 用户忘记密码：在其账号行点击「重置密码」，按提示保存；该用户需用新密码重新登录并再次改密。
5. 离校或不再使用的账号可「停用」，需要恢复时再「启用」。

> 账号和积分菜单依角色开放。若菜单存在但内容空白，或应有的菜单缺失，请联系运维核对权限，不要重复创建账号；这是权限异常，不是“当前没有数据”。

### 8.2 发放积分与核对流水

1. 进入「积分管理」，按姓名或账号找到人员。
2. 点击「调整积分」，选择增加、扣减或设置余额。
3. 输入积分数量和调整原因，提交后仔细阅读确认弹窗，再确认执行。
4. 返回列表核对余额，点击「查看流水」，可分页查看变动、原因、操作人和调整后余额。

**注意**：「设置余额」是把余额改成指定数值，不是在现有余额上再增加；积分不能扣成负数。

### 8.3 交付完成后标记订单

1. 进入「兑换订单」，按订单号、学生姓名、账号或商品搜索。
2. 展开订单，核对商品数量、自提点或送货地点，以及实扣积分。
3. 实物已经交付后，点击「标记完成」并确认。

## 9. 常见问题速查

| 现象 | 先检查什么 | 下一步 |
| --- | --- | --- |
| 学生看不到课堂 | 是否还在「准备中」、是否登录学生端 | 教师把准备好的课堂改为待开播，或直接正常推流 |
| OBS 推流失败 | 服务器和串流密钥是否填反、密钥是否完整或过期 | 获取本场新密钥，保存后重试；仍失败联系管理员 |
| OBS 正常但网页无画面 | 是否同一课堂、是否刚开播、网页是否已过时 | 刷新后点重新连接，等待缓冲，用另一浏览器复核 |
| 网页提示已结束 | 教师是否已停止/暂停推流 | 教师确认 OBS 实际正在输出，不以网页按钮代替推流操作 |
| 手机没有声音 | 默认静音、手机系统音量 | 点击播放器取消静音；教师检查混音器 |
| 教师画面黑屏 | 来源未添加或系统录屏权限未允许 | 在 OBS 本地预览确认画面后再推流 |
| 本场仍显示待配置 | 是否只选了商品、未点绑定按钮 | 点击绑定，核对列表出现商品后再完成 |
| 优惠券没有抵扣 | 是否领取、结算是否选择、是否适用/过期 | 按第 5、6 节核对；不是所有商品都适用 |
| 兑换按钮不可点 | 余额、商品状态、送货地点 | 充值积分、移除下架商品或补齐地点 |
| 停播后暂时没有回放 | 录制/上传仍在处理 | 稍后刷新回放；持续没有则联系管理员 |
| 教师/学生登录互相顶替 | 同浏览器共用登录会话 | 换独立浏览器、无痕窗口或不同设备 |

报障时请提供：发生时间、使用入口、课堂名称、手机/电脑型号、浏览器名称、完整错误提示和截图。**不要提供账号密码或 OBS 串流密钥。**

## 10. 每次开课检查单

### 教师（课前）

- [ ] 登录正确的管理端，核对本场课堂名称。
- [ ] 商品已上架并绑定，优惠券日期/适用课堂正确。
- [ ] OBS 来源有画面、麦克风有波动，H.264 + AAC。
- [ ] 获取本场有效密钥，保存到 OBS 后开始推流。
- [ ] 用学生账号实际确认画面、声音和商品入口。

### 学生（兑换前）
