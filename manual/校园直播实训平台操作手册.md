# 校园直播实训平台操作手册

## 1. 开始使用：账号与登录

平台只有两种角色：**管理员**（即教师，负责开课、商品、账号和积分管理）和**员工**（观看直播、积分兑换）。平台不开放自行注册，账号均由管理员统一创建。

| 角色 | 访问入口 | 主要任务 |
| --- | --- | --- |
| 管理员 | https://live.gaiademo.online/admin | 备课、开播、发放积分、处理订单 |
| 员工 | https://live.gaiademo.online/ | 观看直播、聊天、领券、积分兑换、看回放 |

两个入口使用同一域名下的登录会话。电脑上同时使用两种身份时，请用不同浏览器或无痕窗口，避免互相顶替。

**登录与首次改密（所有人员）**

1. 从管理员处获取账号和初始密码，账号可以是工号、学号等，不必是邮箱。
2. 打开对应入口，输入账号、密码，点击「进入工作台」或「进入课堂」。
3. 首次登录或密码被重置后，必须先修改密码：输入当前密码、新密码、再次确认。
4. **新密码至少 12 位，不能与原密码相同**。保存后用新密码重新登录。

![管理端登录页](screenshots/01-管理端登录.png)

![员工端（学生端）登录页](screenshots/11-学生端登录.png)

忘记密码：联系管理员重置。提示「此入口仅供……使用」：先退出当前账号，再进入对应身份的入口。新建账号的默认初始密码是 `123456`，请以管理员实际通知为准，不要长期使用。

## 2. 管理员：课前准备

### 2.1 查看教学概览

登录管理端后，可查看待开播、直播中、待交付订单和有回放的课堂；左侧栏是各业务模块入口。

![教学概览](screenshots/02-教学概览.png)

### 2.2 创建店铺和直播间

1. 进入「店铺管理」，点击「新建店铺」，填写店铺名称，简介可选，保存。
2. 进入「直播间管理」，点击「新建直播间」，选择所属店铺、填写课堂标题，保存。
3. 在列表点击「配置本场」→「编辑课堂」，将准备好的课堂设为「待开播」。

| 状态 | 含义与处理 |
| --- | --- |
| 准备中 | 草稿，员工不可见；用于备课 |
| 待开播 | 课堂已开放，尚未收到 OBS 推流 |
| 直播中 | OBS 成功推流后自动更新，无需手动设置 |
| 已结束 | 停止推流后自动更新；有录制时可查看回放 |

修改页面状态不会启动或停止直播，真正开播、停播必须在 OBS 中操作。

![直播间管理与配置本场入口](screenshots/03-直播间管理.png)

### 2.3 创建商品并绑定到本场

1. 进入「商品管理」→「新建商品」：选择店铺，填写商品名称、兑换所需积分和自提点，按需填写简介、上传主图（JPG / PNG / WebP，最大 3 MB）。
2. 可选：上传最多 9 张「商品介绍图」，展示在员工端的商品详情弹层中（按添加顺序排列）；编辑时可删除或追加，保存后生效。
3. 保存后确认商品为上架状态。
4. 进入「直播间管理」→ 对应课堂的「配置本场」→「配置商品」：下拉选择**同店铺商品**，填写展示顺序（数字越小越靠前），点击「选好商品后点这里绑定到本场」。
5. 确认弹窗下方列表已出现商品，再点「完成」；重新打开本场配置可核对已绑定数量。
6. **直播中也可随时上/下链接**：课程开播后绑定或解绑商品，员工端小黄车会实时更新并弹出提醒，无需刷新页面。

> **只在下拉框选中商品、然后直接点「完成」，不等于绑定成功**，必须先点绑定按钮。商品管理是资料库，绑定后员工才能在课堂小黄车里看到。

![商品管理](screenshots/05-商品管理.png)

![商品编辑：主图与介绍图](screenshots/05b-商品编辑-介绍图.png)

### 2.4 配置优惠券（可选）

优惠券有两个入口，数据同源：「优惠券」页统一管理各直播间的券；「配置本场」→「设置优惠券」查看本场券列表，需要时点「新建本场优惠券」。券属于指定直播间，创建后无需再"添加"到该课堂。
- **满减门槛（minSpend）**：设置后，学生订单中适用商品合计达到该积分才能使用此券抵扣（例如“满 200 减 30”需适用商品合计 ≥200 积分）；填 0 为无门槛直减。结算页未达标的券会置灰并提示还差多少积分。

新建时填写名称、所属店铺、适用直播间、抵扣积分、到期日期。**规则**：每人每券限领一次、限用一次；只抵扣适用直播间的商品积分，抵扣不超过适用商品的小计；过期或被停用的券不可使用。

## 3. 管理员：OBS 安装、配置和开播

本节按截图步骤逐项操作。不同系统或语言版本中，「直播」「推流」「串流」可能是相近功能的不同译名，以当前界面为准。

### 3.1 安装并跳过引导向导

1. 安装管理员提供的 OBS 安装包。
2. 首次启动会出现「自动配置向导」（默认面向 Twitch 等平台），直接点击「取消」，使用下面的手动配置。

![OBS 启动时取消自动配置向导](screenshots/OBS-1-取消引导.jpg)

### 3.2 打开设置

在 OBS 主界面右下角点击「设置」按钮（控件栏最右侧的齿轮图标）。

![点击右下角设置按钮](screenshots/OBS-2-点击设置.jpg)

### 3.3 填写推流服务器与串流密钥

先在平台管理端进入「直播间管理」→「配置本场」→「获取 OBS 设置」，弹窗中有「OBS 服务器」和「OBS 串流密钥」两项。然后在 OBS「设置」→「流」页：

| 字段 | 填写内容 |
| --- | --- |
| 服务 | 自定义 |
| 服务器 | 平台弹窗中的「OBS 服务器」 |
| 串流密钥/推流码 | 平台弹窗中的完整「OBS 串流密钥」 |

![设置 → 流：服务选自定义，填服务器与推流码](screenshots/OBS-3-设置推流服务器.jpg)

![回到平台弹窗点复制，粘贴到 OBS 对应输入框](screenshots/OBS-4-复制粘贴推流码.jpg)

**服务器格式示例**：

```text
rtmp://live.gaiademo.online:1935/live
```

**串流密钥格式示例（不是可用密钥）**：

```text
本场流名?token=系统生成的签名&expire=系统生成的时间戳
```


### 3.4 设置视频与音频码率

OBS「设置」→「输出」：输出模式选「简单」，按建议值填写：

| 配置项 | 建议值 |
| --- | --- |
| 视频码率 | **1200 Kbps**（教学画面 720p 足够清晰，存储与带宽占用小） |
| 音频码率 | 96 或 128 Kbps |
| 编码器 | 有硬件编码（如 NVIDIA NVENC）优先选，没有则用默认 x264 |

**降低延迟（推荐）**：OBS「设置」→「输出」→ 输出模式选「高级」→「串流」页：

| 配置项 | 建议值 | 作用 |
| --- | --- | --- |
| 关键帧间隔 | **1 秒** | 对延迟影响最大；默认 2~4 秒会让观看延迟多出几秒 |
| x264 预设 | veryfast | 降低编码延迟与 CPU 占用 |

> 关键帧间隔越小延迟越低，但同码率下画质路降；若追求画质可保持 1200~1500 Kbps 码率不变。按上述设置，主流浏览器（HTTP-FLV 拉流）延迟约 2~3 秒；Safari 兑底（HLS）约 6~8 秒。

![设置 → 输出：视频码率与音频码率](screenshots/OBS-5-设置码率.jpg)

### 3.4.1 竖屏直播（手机风格画面，可选）

平台播放器会按实际画面比例自动展示，横屏、竖屏推流都无需改平台配置，只需设置 OBS 画布：

1. OBS「设置」→「视频」：基础（画布）分辨率与输出（缩放）分辨率都设为 **720×1280**（竖屏 9:16）；缩小方法选「双三次」。
2. 在来源里正常添加摄像头/窗口；竖屏画布下建议只保留主体画面，避免字幕太小。
3. 码率建议仍用 1200~1500 Kbps（竖屏 720×1280 与横屏 1280×720 像素量相同）。

> 员工端播放器会自动以 9:16 居中展示竖屏画面，不会拉伸变形；回放同样自适应。手机直接推流的画面天然是竖屏，无需任何设置。

![竖屏直播：画面按 9:16 居中展示](screenshots/13c-学生端-竖屏直播.png)


### 3.5 开启网络优化（抗卡顿，必做）

OBS「设置」→「高级」→「网络」，把以下三项全部勾上：

| 选项 | 作用 |
| --- | --- |
| 动态调整码率以管理拥塞 | 网络变差时自动降码率，避免断流 |
| 网络优化 | 优化推流连接的拥塞处理与重连 |
| TCP pacing | 匀速发送数据，避免突发丢包 |

![设置 → 高级 → 网络：三项抗卡顿开关全部勾选](screenshots/OBS-6-设置网络优化.jpg)

### 3.6 添加画面和声音来源

1. 在主界面「来源」区域右键点击，选择「添加」→「窗口采集」（直播某个软件窗口）或「显示器采集」（直播整个屏幕），选中要共享的窗口。
2. 需要出镜时再添加「视频采集设备」选择摄像头，拖动缩放到画面角落。
3. macOS 首次采集若提示权限，到「系统设置 → 隐私与安全性」允许 OBS 录屏、麦克风、摄像头，按提示重新打开 OBS。
4. 在预览画面中右击来源 →「变换」→「适配屏幕」，避免只显示局部画面。
5. 对着麦克风说话，确认「混音器」对应音量条有波动且未静音。

![来源面板点＋，添加窗口采集并选择窗口](screenshots/OBS-7-添加窗口采集.jpg)

> 直播前关闭私人聊天、通知和敏感窗口。不要把正在播放直播的网页也采集进去，以免无限套屏；员工端试听时戴耳机，避免回声。

### 3.7 开播与停播

**开播检查**：预览有画面 → 麦克风有波动 → 本场服务器/密钥已填好 → 点击右下角「开始直播/开始推流」。

1. OBS 出现推流时长和输出码率后，返回平台查看课堂是否变为「直播中」（必要时刷新页面）。
2. 用另一浏览器或手机，以员工账号进入同一课堂，确认有画面、能听到声音。
3. 员工手机端首次起播可能需要等待缓冲；没有声音先点击播放器取消静音。
4. 下课后，在 OBS 点击「停止直播/停止推流」，课堂随后变为「已结束」。
5. 等待录制完成、上传后，在平台「查看回放」检查；长场次上传需要更久。

![右下角控件：开始推流与停止推流按钮](screenshots/OBS-8-开始与结束直播.jpg)

## 4. 管理员：账号、积分与订单交付

### 4.1 建号和密码重置

1. 进入「账号管理」→「新建账号」：填写登录账号，选择教师或学生角色；姓名可不填，不填时使用账号作为显示名。
2. 默认初始密码为 `123456`，可按学校要求修改；保存后单独通知本人账号、初始密码和正确入口。
3. **批量建号（整班导入）**：点击「下载导入模板」得到 Excel，按列填写：账号（必填）、姓名（选填）、角色（学生/教师，默认学生）、初始密码（选填，默认 123456）；回到页面点「批量导入账号」上传该文件。单次最多 500 行，导入结果会列出成功数量和每行失败原因（如账号重复、格式不正确）。所有新账号首次登录必须改密。
4. 用户忘记密码：在其账号行点击「重置密码」；该用户需用新密码重新登录并再次改密。
5. 离校或不再使用的账号可「停用」，需要恢复时再「启用」。

![账号管理：模板下载与批量导入](screenshots/08b-账号管理-批量导入.png)

> 账号和积分菜单依角色开放。若菜单存在但内容空白，或应有的菜单缺失，属于权限异常，请联系平台负责人核对，不要重复创建账号。

### 4.2 发放积分与核对流水

1. 进入「积分管理」，按姓名或账号找到人员，点击「调整积分」。
2. 选择增加、扣减或设置余额，输入积分数量和调整原因，提交后在确认弹窗中仔细核对，再确认执行。
3. **批量赋分（多选）**：勾选多个账号后点「批量赋分」，选择操作方式并输入每人积分数量和原因，确认后逐人执行；每人各记一条流水，部分失败不影响其他人，可安全重试（已成功者不会重复调整）。单次最多 500 人。
4. 返回列表核对余额；点击「查看流水」可分页查看变动、原因、操作人和调整后余额。

> 「设置余额」是把余额改成指定数值，不是在现有余额上再增加；积分不能扣成负数。

![积分管理：多选后批量赋分](screenshots/09b-积分管理-批量赋分.png)

### 4.3 交付完成后标记订单

进入「兑换订单」，按订单号、员工姓名、账号或商品搜索；展开订单核对商品数量、自提点或送货地点以及实扣积分；**实物已经交付后**，点击「标记完成」并确认。

![管理端兑换订单](screenshots/07-兑换订单.png)

## 5. 员工：观看直播、聊天和领券

### 5.1 进入课堂

1. 打开学生端（员工入口），使用管理员分配的账号登录；首次使用先改密。
2. 在「直播课堂」中找到管理员通知的课堂，点击「进入课堂」；可按课堂名称或店铺搜索。
3. 管理员也可分享课堂链接，但链接不能代替登录权限。

![员工端课堂列表](screenshots/12-学生端-直播课堂列表.png)

### 5.2 播放、声音与互动

- 等待播放器出现画面后点击播放；默认静音时，点击播放器音量按钮开启声音。
- 手机可用浏览器全屏或横屏观看；微信内无法正常播放时，尝试「在浏览器打开」。
- 在「课堂互动」输入文字后发送；不要频繁连续发送，不要发送密码、地址等私人信息。
- 手机观看与电脑画面可能有时间差，不代表直播出问题。

截图中的彩条是制作手册时的测试画面，正式课堂显示管理员通过 OBS 发送的内容。

![员工观看与课堂互动](screenshots/13-学生端-直播间观看.png)

### 5.3 领取优惠券与选商品

1. 找到「本场优惠券」或点击「领券」，在需要的券旁点击「领取」。
2. 在「本场商品」中核对名称、积分价格，点击「加入」；点击「详情」可查看商品大图、介绍图、简介与自提点。手机端可点击「本场商品」「已选商品」或购物车入口展开小黄车。
3. 直播中教师上新或下架商品时，小黄车会自动更新并弹出提醒，无需刷新页面。
4. 已领取不等于已使用，兑换时还需要在结算页选择该券。

![学生端：商品详情弹层（介绍图）](screenshots/13b-学生端-商品详情.png)

## 6. 员工：积分兑换、提货与订单

1. 进入「购物车」或本场「已选商品」，确认商品和数量，移除不需要的商品。
2. 点击「去兑换」，核对积分余额、商品所需积分。
3. 在「使用已领取的优惠券」中选择适用券，核对优惠抵扣及实际扣除积分。
4. 选择交付方式：

| 交付方式 | 操作要求 |
| --- | --- |
| 自提（默认） | 查看各商品的自提点，按学校约定时间到现场领取 |
| 送货 | 填写准确送货地点（楼栋、房间或约定地点）；未填写不能提交 |

5. 核对无误后点「确认积分兑换」。余额不足时联系管理员充值，平台不涉及在线支付。
6. 成功后进入「我的订单」，核对订单编号、商品、扣除积分与交付方式。
7. 自提时向工作人员出示订单；送货的按学校约定方式等待线下交付，平台不提供快递轨迹。

![积分兑换结算示例](screenshots/14-学生端-积分兑换结算.png)

> 截图为结算演示：余额为 0，尚未成功兑换；正式操作请确保余额足够，并滚动到结算抽屉底部查看提交按钮。

![我的订单入口（无订单时的示例）](screenshots/15-学生端-我的订单.png)

提交时遇到网络错误：先到「我的订单」确认是否已生成订单，避免反复提交。商品价格变化、下架、券过期等情况，请重新核对后再兑换。

## 7. 回放：员工与管理员

**员工**：打开「课程回放」→ 选择课堂 → 点击相应录制的「播放回放」。**管理员**：「直播间管理」→「配置本场」→「查看回放」。

- 一间课堂可能有多条回放（暂停/断开重推会形成新录制），按日期时间选择。
- 支持暂停、拖动和调节音量；手机端受浏览器策略影响时点击播放。
- 回放默认最多保留 180 天；磁盘紧张时可能从最旧的开始提前清理，但不会删除未满 90 天的回放。重要内容请提前与管理员约定留存。

## 8. 常见问题速查

| 现象 | 先检查什么 | 下一步 |
| --- | --- | --- |
| 员工看不到课堂 | 是否还在「准备中」、是否登录学生端 | 管理员把课堂改为待开播，或直接正常推流 |
| OBS 推流失败 | 服务器和串流密钥是否填反、密钥是否完整或过期 | 获取本场新密钥保存后重试；仍失败联系管理员 |
| OBS 正常但网页无画面 | 是否同一课堂、是否刚开播、网页是否已过时 | 刷新后点重新连接，等待缓冲，用另一浏览器复核 |
| 网页提示已结束 | 管理员是否已停止/暂停推流 | 在 OBS 确认实际正在输出，不以网页按钮代替推流 |
| 手机没有声音 | 默认静音、手机系统音量 | 点击播放器取消静音；管理员检查混音器 |
| 画面黑屏 | 来源未添加或系统录屏权限未允许 | 在 OBS 本地预览确认画面后再推流 |
| 本场仍显示待配置 | 是否只选了商品、未点绑定按钮 | 点击绑定，核对列表出现商品后再完成 |
| 优惠券没有抵扣 | 是否领取、结算是否选择、是否适用/过期 | 按第 5、6 节核对；不是所有商品都适用 |
| 兑换按钮不可点 | 余额、商品状态、送货地点 | 充值积分、移除下架商品或补齐地点 |
| 停播后暂时没有回放 | 录制/上传仍在处理 | 稍后刷新回放；持续没有则联系管理员 |
| 两种身份互相顶替 | 同浏览器共用登录会话 | 换独立浏览器、无痕窗口或不同设备 |

报障时请提供：发生时间、使用入口、课堂名称、设备型号、浏览器名称、完整错误提示和截图。**不要提供账号密码或 OBS 串流密钥。**

## 9. 开课检查单

### 管理员（课前）

- [ ] 登录正确的管理端，核对本场课堂名称。
- [ ] 商品已上架并绑定，优惠券日期/适用课堂正确。
- [ ] OBS 来源有画面、麦克风有波动，H.264 + AAC。
- [ ] 获取本场有效密钥，保存到 OBS 后开始推流。
- [ ] 用员工账号实际确认画面、声音和商品入口。

### 员工（兑换前）

- [ ] 登录本人账号，进入管理员通知的课堂。
- [ ] 核对积分余额、商品、数量和优惠券。
- [ ] 确认自提点，或填准送货地点。
- [ ] 成功后核对「我的订单」，按学校约定领取商品。

### 管理员（下课）

- [ ] 在 OBS 停止推流，而不是只关闭平台网页。
- [ ] 核对课堂结束状态，稍后检查回放。
- [ ] 实物交付后再标记订单完成。
